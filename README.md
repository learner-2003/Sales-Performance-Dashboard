# Sales Performance Dashboard – Power BI

##  Project Overview
This project focuses on analyzing sales performance using Microsoft Power BI. An interactive dashboard was developed to understand revenue, compare sales across countries, and identify the most profitable products.

## Project Objectives
- Analyze Total Revenue.
- Visualize Sales by Country.
- Identify the Top 5 Products by Profit.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- DAX (Data Analysis Expressions)

## Dataset Description
The dataset contains 700 sales records with 16 columns, including:
- Country
- Product
- Units Sold
- Sales
- Gross Sales
- Profit
- Date

##  Dashboard Features

### 1. Total Revenue
Displays the overall revenue generated from sales.

### 2. Sales by Country
Visualizes and compares sales performance across five countries:
- Canada
- France
- Germany
- Mexico
- United States of America

### 3. Top 5 Products by Profit
Highlights the five most profitable products based on total profit.
